# 6-STEP DANCE STUDIO

Premium black-and-gold React + Vite dance studio website.

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Edit client details

Update `src/data/studioData.js` for:
- studio name
- phone numbers
- WhatsApp number
- choreographer name
- experience
- Instagram
- location

## Main sections

Home, About + Choreographer, Services, Why Choose 6-STEP, Programs, Testimonials, Booking/WhatsApp enquiry and Contact.

No backend is required for the current enquiry flow: the form opens WhatsApp with the entered details.
